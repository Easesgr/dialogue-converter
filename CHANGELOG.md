# Changelog

## 0.3.0 — 2026-10-12

- First public release of the native macOS application.
- Bundled converter runtime, architecture-specific DMG/ZIP packaging and checksums.
- Bidirectional native Claude Code / Codex adapters, conservative completion detection and explicit delivery acknowledgement.
- Handoff history with reopening, delivery status and exact artifact verification.
- Compact or complete text copying, full Markdown export, configurable app and data paths, and keyboard shortcuts.
- Synthetic demo mode, build/release automation, privacy and contributor documentation.

## 0.2.0

Local prototype with the native window, transcript adapters, incremental handoffs and source watching. It required the maintainer's Python installation and was not distributed.
