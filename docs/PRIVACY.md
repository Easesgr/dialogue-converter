# 隐私与资料保存

转换器读取你选择的本机 Cowork 或 Codex 会话。自动发现只访问已知会话目录；不扫描浏览器资料或读取认证文件。

## 转换内容

转换用户与助手的可见文字，保留角色、顺序与全文。结构化私有推理、工具输入输出、系统 / 开发者消息、压缩摘要替代、附件内容不进入导出。用户或助手正文中已经出现的秘密、个人信息与路径会原样保留，工具不保证自动脱敏。

新建 Cowork 导入包只写最少会话元数据、清理后的消息链与原生清单。不复制源资料中的 API Key、权限、系统提示、文件授权、审计 HMAC 或模型选项。ZIP 内容未加密。

## 本机写入

~~~text
~/Library/Application Support/DialogueConverter/
  conversions/<UUID>/receipt.json
  conversions/<UUID>/dialogue.json
  conversions/<UUID>/Cowork-conversation.zip
  conversions/<UUID>/staging-home/.claude/projects/…/….jsonl
~~~

目录权限 0700，转换文件 0600。转换记录包含来源、目标编号、标题、项目、本机路径与导入状态。偏好设置保存应用与资料目录路径，不保存认证信息。0.3.0 的旧 packets、进度与发现缓存可能仍在同一资料目录中。

源会话只读。Codex 的原生导入接口创建新会话并写入 Codex 管理的历史与索引。工具不给已有活跃会话追加内容。Cowork 导入由 Claude 自己的界面与会话管理器完成。

## 网络与模型

转换器自身没有远程网络客户端，不调用模型。它通过 stdio 启动本机 Codex 内置 app-server，使用会话导入与读回协议；原程序可能有自己的网络访问、模型目录更新或遥测行为。转换器不发送模型执行请求。

打开原应用、导入并继续对话后，原应用与所选服务商按其设置处理内容。模型缓存、推理状态、工具状态与用量不能跨产品保留。

## 清除

退出转换器后可删除 .app。保留需要的转换包后，可通过 Finder 删除 DialogueConverter 资料目录。已经导入 Codex 或 Cowork 的目标会话需要在原应用中另行删除；删除转换资料不会删除原应用会话。

提交问题时只提供合成或脱敏记录。不要提交真实导出包、认证文件、访问令牌或整个个人资料目录。
