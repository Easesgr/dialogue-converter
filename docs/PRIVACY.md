# 隐私说明

转换模块不进行网络请求、模型调用或遥测。应用只读取你选择的对话文件，以及为列出会话而读取的本机 Claude Code / Codex 索引和记录。原生会话文件不会修改。

转换会排除结构化记录中的私有推理、系统/开发者消息和工具数据。手动粘贴的纯文本无法判断哪些文字属于敏感内容，请在粘贴前选择需要交接的可见内容。

## 保存的资料

`~/Library/Application Support/DialogueConverter/` 包含：

- `state.json`：各来源/目标对话对的交付进度、指纹与确认记录。
- `discovery-cache.json`：会话标题、目录、时间、完成状态等快速发现缓存。
- `packets/<UUID>/`：完整可见交接 Markdown、可见消息 JSON 和交接元数据。
- `state.lock`：进程间锁。

目录权限为 `0700`，文件权限为 `0600`。资料只保存在本机；它们没有加密，Mac 的磁盘保护取决于系统设置。应用偏好设置包含选择的来源、目标、项目和应用/数据目录，不保存 API Key。

剪贴板由系统管理，其他获准访问剪贴板的软件可能读到复制的内容。导出文件包含可见对话及项目路径，分享前请检查。

## 清理与卸载

退出应用后可删除 `.app`。如果也需要清除交接记录，保留需要的资料后在 Finder 中删除上述 `DialogueConverter` 资料目录。这样会重置交接进度，重新转换时将再次包含全部可见内容。无需删除 Claude 或 Codex 的原始数据。

应用中的“帮助”会在浏览器中打开 GitHub；“复制并打开”会启动你选择的原应用。原应用的网络行为由该应用自行管理。
