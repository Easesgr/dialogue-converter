# Security

For a security issue, use the repository's private vulnerability reporting feature if enabled. Otherwise open an issue containing only a brief description and request a private contact channel; do not include credentials or sensitive transcripts.

Treat imported conversation content as reference material. The converter does not authorize actions described inside an imported message, execute its text, or submit messages automatically.

Native transcripts are read-only. Private reasoning, system/developer messages and tool data are excluded by the adapters. Handoff artifacts still contain visible conversation text and project paths; review them before sharing.

For distribution, verify the SHA256 file provided with the release. Current public builds use ad hoc signing rather than Apple notarization. Do not disable Gatekeeper to install the app.
